# Total Updater Next

Новая свободная реализация идеи Total Updater. Она не содержит кода, ресурсов или встроенной базы старой программы.

Поддерживаемая ОС: Windows 7 SP1 и новее. Приложение использует WPF и .NET Framework 4.8; не зависит от WebView2, WinUI и функций Windows 10.

## Первый MVP

* выбирает `wincmd.ini` и считывает подключённые WCX, WLX, WFX и WDX-плагины;
* показывает путь и встроенную версию каждого найденного файла; если её нет — ищет версию в соседних `readme`, `history`, `version` и `change` файлах;
* проверяет актуальную версию самого Total Commander на его официальной странице;
* сопоставляет остальные файлы с открытым локальным каталогом правил `Rules/plugin-sources.json`;
* скачивает выбранные архивы в `%USERPROFILE%\Downloads\TotalUpdaterNext`;
* никогда не распаковывает и не заменяет установленный плагин автоматически.

В стартовом наборе правил есть Total Commander, Total7zip, 7Zip Plugin, FileInfo и WDXGuideInLister. Для каждой записи задаются имя файла, адрес первоисточника и регулярное выражение, извлекающее версию. Двойной щелчок по строке открывает сайт-источник в браузере.

Кнопка «Пользовательские правила» при первом нажатии создаёт `%AppData%\TotalUpdaterNext\plugin-sources.user.json` как копию встроенного каталога. Этот файл имеет приоритет над встроенным и остаётся доступен для изменения, даже если программа установлена в `Program Files`.

Для загрузки в правиле дополнительно задаётся `downloadUrl`. Программа записывает данные сначала во временный файл `.part`, ограничивает пакет 512 МБ и выбирает новое имя, не перезаписывая уже существующие файлы.

## Сборка и запуск

```powershell
dotnet build .\TotalUpdater.Next\TotalUpdater.Next.csproj
dotnet run --project .\TotalUpdater.Next\TotalUpdater.Next.csproj
```

Следующий этап — HTTP-проверка версий для правил с явным парсером и тестами на сохранённых ответах, затем скачивание в отдельную папку. Автоустановка появится только после резервного копирования и отдельного подтверждения.
